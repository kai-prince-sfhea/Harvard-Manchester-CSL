# Security and reporting

This is an unreleased standalone CSL style. There is no supported stable release
or response-time commitment. It bundles no JavaScript, Lua filter, model or
network service. The consuming application's parser and document renderer have
their own security and update requirements.

Report non-sensitive style defects through the repository's
[issues](https://github.com/kai-prince-sfhea/Harvard-Manchester-CSL/issues), using
a minimal fictional record and the application/processor version.

For a suspected security vulnerability, first request a private contact channel
from the maintainer without posting exploit details or confidential records.
Use GitHub's private reporting interface only if the repository offers it;
this document does not claim that it is enabled. Public issues are public.

Bibliographic `note` and other displayed fields, URLs and generated references
can expose supplied data. Remove personal or confidential material from a
reproduction before sharing it. See [AUTHORING.md](AUTHORING.md) for fields that
can be displayed in ordinary output.
